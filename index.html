Super Banana Studios

This page exists to host one thing: the command that takes a bare machine to a working checkout of one of our projects. It installs git, Git LFS and the GitHub CLI, signs you in as yourself, and then runs that project's own setup script.

Windows 11 (x64), in PowerShell

& ([scriptblock]::Create((irm https://super-banana-studios.github.io/setup.ps1))) -Repo <owner>/<repo>

macOS (Apple Silicon), in Terminal

/bin/bash -c "$(curl -fsSL https://super-banana-studios.github.io/setup.sh)" -- <owner>/<repo>

Ask the person who onboarded you for the line - theirs already carries the project, and some projects have a shorter form of it. You need local administrator rights on the machine and a GitHub account that is already a member of the organization.

The scripts are here.
